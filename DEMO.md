# СМЕНА 74 — тестовый UI-стенд

Этот репозиторий предназначен **только для демонстрации** механики будущего Telegram Mini App. Исходная CRM и React Mini App из архива пользователя сюда целиком **не загружены**: они содержат незавершённые интеграции и зависят от Cloudflare D1.

## Возможности демо

- Переключение между заказчиком, исполнителем и диспетчером
- Создание тестовой заявки
- Одобрение и отклонение заявки
- Отклик работника и тестовое назначение
- Сохранение тестовых данных в `localStorage` конкретного браузера и сброс

**Важное ограничение:** этот интерфейс не применяет реальную Telegram-авторизацию и разграничение доступа, не отправляет заявки в CRM и не содержит webhook. Нельзя использовать его как production.

## Vercel

Подключите этот репозиторий как новый проект Vercel. Framework Preset: `Other`; Root Directory: `./`; Build Command: пусто; Output Directory: пусто. Статический `index.html` доступен по корню тестового домена.

Для полноценного приложения необходимо реализовать серверную проверку Telegram initData, роли и права доступа на сервере, REST API, общую БД и отдельно настроить тестовый webhook бота.
