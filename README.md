# СМЕНА 74 — тестовый стенд

Тестовый репозиторий для демонстрации механики Telegram Mini App. **Не production.**

> Исходный архив содержит CRM (Next/Vinext + Cloudflare D1) и незавершённый React/Vite Mini App. Для изолированного тестирования здесь будет отдельный UI-прототип без настоящих платежей, Telegram-авторизации и рабочих заявок.

## Что требуется для полноценного запуска

- Доработать Mini App: API авторизации, страницы исполнителя/администратора, сценарий заявки.
- Настроить backend + общую БД и проверку Telegram initData на сервере.
- Настроить отдельно тестового Telegram-бота с HTTPS webhook.
- Подключить Vercel к этому репозиторию для Preview-деплоя.

Никакие токены или реальные данные заказчиков в публичный тестовый репозиторий не загружаются.
